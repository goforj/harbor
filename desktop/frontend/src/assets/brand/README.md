# Project identity artwork

`goforj-ios.png` is an unmodified copy of `goforj-docs/docs/public/apple-touch-icon.png`, the current orange GoForj iOS icon. Use it for offline GoForj projects and as their online favicon fallback. Keep project identities separate from Harbor's anchor application icon and resource-kind glyphs.

Update this asset from the canonical docs source when GoForj branding changes. Preserve its alpha, proportions, and colors; do not redraw it or substitute an old cube mark.
